# Veyra Connect v1.0.0 beta 1

This is a **preview** release, not general availability.

- One standalone double-click Windows BAT installer.
- Per-user installation and desktop shortcuts.
- Local ByeDPI (ciadpi) SOCKS5 proxy using pinned official SHA-256 downloads.
- Discord TCP launch parameters, status tests, optional owner-controlled network configuration and uninstall.

Known limits: Discord voice/stream UDP is not routed transparently through Chromium SOCKS5. Call of Duty and Discord coexistence is not guaranteed on every PC. End-to-end gaming tests have not been performed for this public package.

Source: https://github.com/Naveax/Veyra-Connect
ByeDPI: https://github.com/hufrea/byedpi
